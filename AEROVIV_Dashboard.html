ESP32 DATA FORMAT

Open this file from your laptop (double-click) so it can reach the ESP32 on your Wi-Fi. Return JSON like this from http://IP/data, or push it over a WebSocket. lat/lon are optional (GPS tracker).

{"current":12.4,"ldr":2310,"led":1,"ax":0.01,"ay":-0.02,"az":0.98,"lat":12.97,"lon":77.59}

// ESP32 Arduino (WebServer.h) - CORS header is required
server.on("/data", [](){
  server.sendHeader("Access-Control-Allow-Origin","*");
  server.send(200,"application/json",
   "{\"current\":"+String(mA)+",\"ldr\":"+String(ldr)+",\"led\":"+String(led)+
   ",\"ax\":"+String(ax)+",\"ay\":"+String(ay)+",\"az\":"+String(az)+
   ",\"lat\":"+String(lat,6)+",\"lon\":"+String(lon,6)+"}");
});
